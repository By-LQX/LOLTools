# LOLTools

LQX 的 Windows 游戏辅助工具。

本仓库用于公开发布程序、更新说明和自动更新文件。

## 下载

前往 [Releases](https://github.com/By-LQX/LOLTools/releases/latest) 获取最新版本：

- `LOLTools_版本_x64-setup.exe`：安装版。
- `LOLTools_版本_x64.exe`：免安装版，下载后直接运行。
- `LOLTools_版本_x64-portable.7z`：软件自动更新使用的免安装包。

首次使用启用自动更新的版本时，需要手动安装或更换程序一次。之后可在软件内检查更新。

## 软件激活

从 1.0.1 起，首次启动需要输入适用于 `LOLTools` 的 CDK。永久授权支持离线使用；限时授权启动时需要联网校时。授权信息和续期入口位于“设置 → 关于 → 软件授权”。
